# Create a project verification skill

This is a repository-changing coordinator capability and is not available to the read-only product verifier.
Create a project-local skill with launch, doctor, drive, evidence, and cleanup procedures.
Add a user-facing feature map that names supported scenarios and their observable evidence.
Use repository-native commands and control surfaces, document unavailable dependencies honestly, and leave the repository clean after verification.
