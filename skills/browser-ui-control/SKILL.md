# Browser and UI control

Use chrome-devtools-axi when it is installed and reachable from the verification environment.
Launch or attach through the project's supported command, drive the user-facing scenario, and capture concrete screenshots, console, network, and DOM observations.
Do not edit product files during verification.
Return inconclusive with the unavailable browser control surface and required next action when chrome-devtools-axi is unavailable.
